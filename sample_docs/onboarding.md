# Widget Platform — Onboarding Order

New tenants must be set up in a strict order because each step depends on the
previous one.

## Step 1 — Roles
Create user roles first. Roles control who can approve widget requests. If roles
are not set up, the Approve button never appears for any user.

## Step 2 — Categories
Create widget categories. Every widget must belong to a category, so categories
must exist before any widget can be created.

## Step 3 — Suppliers
Register suppliers. A widget links to a default supplier, so at least one
supplier must exist and be approved before widgets are created.

## Step 4 — Widgets
Only after roles, categories, and suppliers exist can widgets be created and
routed for approval.
